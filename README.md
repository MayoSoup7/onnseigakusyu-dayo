# 英語耳 v10

Lesson 01〜26対応の個人用PWAです。

## 今回の修正
- 上部の「☀️」「📖 本を読む」を固定ヘッダー化。iPhoneでスクロールしても押せます。
- 「非表示」は画像そのものを削除・再生成せず、現在の画面上で即時非表示にします。
- 非表示にしたページは「🙈 非表示ページ」から「👁 再表示」できます。
- 非表示にしてもページ画像・Practice・音声は削除しません。
- 本を読むモードでは非表示ページを飛ばします。
- 本を読む中は上部ボタンが「✏️ 本を編集」になり、押すと編集画面へ戻ります。
- 既存の v9 データベース `eigomimi-v9` をそのまま使用するため、v9で登録済みの画像・音声を引き継ぎます。

## 注意
教材画像・音声はGitHub Pagesへアップロードせず、ブラウザ内に保存してください。
