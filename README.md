# 英語耳 PWA v14

v13のデータ構造を引き継ぐ改修版です。

- Lesson 01〜26の選択肢をHTML側にも保持し、Lesson選択が空になる問題を防止
- 「🎵 音声ライブラリ」をLesson編集から独立した画面として追加
- 音声はLessonに紐づけず全体ライブラリへ登録
- 音声ライブラリからタイトル変更、削除、再生、↑↓、番号入力による順番変更が可能
- 各ページの「＋Practice」から音声を複数選択して一括追加
- 本を読むモードではLessonごとの非表示／再表示をその場で切替
- 非表示状態はpageStatesだけを更新し、ページ画像Blobを変更しない
- 既存DB名 eigomimi-v9 を維持して既存データを引き継ぐ
- ユーザー提供のicon.pngをそのまま使用
